# Particle textures

`fog.png` and `fogcolors.png` are unmodified assets from the OpenRobotics
**Fog Generator** model on Gazebo Fuel:

https://fuel.gazebosim.org/1.0/OpenRobotics/models/Fog%20Generator

Author: Nate Koenig / OpenRobotics

License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

The files are used by `examples/worlds/ouster_smoke.sdf` following Gazebo
Sim's documented particle-emitter material setup.
